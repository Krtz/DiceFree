# Dungeons, Death and Failure

## Death outside a wipe

When a character dies:
- another player can resurrect them if an available class/ability allows it;
- some classes may have self-revive mechanics;
- otherwise the character respawns at an appropriate camp/checkpoint.

Death carries a modest penalty:
- lose some gold;
- lose a **small** amount of experience.

Exact percentages and whether experience loss can reduce a level remain to be balanced later.

## Dungeon wipes

The primary punishment in group dungeon/raid content is the **wipe**, not a huge per-death character penalty.

If the party fully wipes:
- the dungeon run resets;
- the party receives no completion loot from that failed run.

This should make successful clears meaningful without making an individual death catastrophically punishing.

Exact reset boundaries still need design:
- whole dungeon versus current wing/checkpoint;
- treatment of already-defeated optional bosses;
- procedural seed reset behaviour;
- raid reset behaviour;
- disconnect/rejoin handling.

## Resurrection design

Resurrection is class/system-dependent rather than universally available.

Potential sources:
- another player's class ability;
- self-revive class mechanics;
- rare encounter/item effects if later desired.

Powerful resurrection access should have tradeoffs and should not trivialize wipe mechanics.

## Dungeon construction

Most dungeons are handcrafted.

Some dungeon types may use procedural or RNG-generated layouts/content.

This mix lets important story/boss spaces stay authored while supporting replayable formats elsewhere.

## Difficulty modes

Dungeons and raids can have multiple modes.

Harder modes should increase more than raw stats. They can add:
- new boss mechanics;
- altered phases;
- tighter timing;
- additional enemy behaviours;
- changed arena hazards;
- stronger stat tuning;
- mode-specific loot tables/rewards.

Exact mode names and progression are not yet locked.
