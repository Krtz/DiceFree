# Character Identity and Appearance

## The Echo

The player is an **Echo** of the survivor from DiceBound.

The Echo does not begin as a heavily customized traditional RPG avatar. Instead, as in DiceBound, it gains a stronger shape and identity through class choice and advancement.

## Novice appearance

Novice is intentionally androgynous and visually uncommitted.

A fresh Echo begins:
- with no equipped gear;
- in simple baseline underwear + T-shirt;
- without a strong masculine/feminine class silhouette;
- without a recognizable warrior/mage/rogue/healer identity.

This baseline clothing is presentation, not equipped armor.

Novice-compatible starter gear is deliberately limited to items explicitly allowed for Novice.

## Appearance philosophy

The class itself is the primary character visual identity.

A class should define things such as:
- body/form/silhouette;
- animation flavour;
- class VFX;
- equipment compatibility;
- visual evolution on advancement.

Equipped gear then makes individual characters within that class lineage more unique.

## Character creator

A broad face/body/hair character creator is **not planned**.

A very small presentation choice such as boy/girl/undefined may be considered later, but only if it does not multiply the armor/animation production burden beyond what is sensible.

The technical art pipeline should therefore avoid promising multiple incompatible body rigs before we know the cost.

## Equipment

Not every class can use every type of equipment.

Gear visibility and class identity must work together:
- armor should fit the supported class/body rigs;
- weapons must attach correctly;
- restrictions can reinforce class fantasy;
- advancement may change available equipment categories.

## Technical implication

Before large-scale character or armor production:
1. decide how many base rigs/forms actually need to exist;
2. establish skeleton/socket conventions;
3. test visible equipment on meaningfully different classes;
4. prove the Blender -> Unity pipeline;
5. only then scale content production.
