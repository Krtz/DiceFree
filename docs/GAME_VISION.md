# Game Vision

## Elevator pitch

DiceFree is a persistent isometric 3D action RPG for solo play and eventual co-op. The player is an **Echo** of the survivor who escaped the inside of the Dice after the defeat of The Last Equation.

Every character begins as a Novice and repeatedly advances into increasingly specialized permanent class lineages while exploring the six outer faces of the Dice, running dangerous dungeons, hunting meaningful equipment and discovering secret progression paths.

## Core fantasy

**Start without a shape. Become something ridiculous.**

The Echo gains identity through class advancement.

Class choice should be one of the game's strongest emotional and visual beats. A transformation can alter abilities, passives, stat growth, equipment permissions, visuals and playstyle.

Equipped gear then makes each instance of that class more personally distinctive.

## Pillars

### 1. Class evolution
The class tree should feel like a lineage. Choices are permanent on a character and advancement can add, evolve or replace abilities.

### 2. Persistent world progression
Characters persist between sessions. Six overworld faces, quests, dungeons, raids, difficulty modes and bosses create a long progression ladder.

### 3. Dungeon-earned loot
Drops should be more deliberate than a constant loot shower. Drop tables matter, and successful dungeon/raid completion is a major source of equipment.

### 4. Discoverable secrets
Not every class, boss, item or system should be visible from the beginning. Achievements, hidden conditions and world interactions can reveal new paths.

### 5. Visible character growth
The class form itself is the primary character appearance. Equipped gear must visibly customize that form wherever practical.

### 6. Solo viable, co-op excellent
A player should be able to progress alone. Co-op should add synergy, resurrection and group possibilities without forcing a rigid MMO trinity for ordinary progression.

### 7. Positioning-first combat
Classic mouse movement is the primary balance target. There is no universal dodge; movement speed and mobility tools are part of class identity.

## Inspirations

Primary structural inspiration:
- Warcraft III persistent ORPG custom maps, especially Twilight's Eve ORPG.

Design DNA carried from DiceBound:
- secret class unlocks;
- account progression;
- escalating difficulty modes;
- build-changing legendary/mythical loot;
- strange and funny classes;
- bosses, secret bosses and achievements;
- a willingness to let systems become gloriously deep.

DiceFree must remain an original game rather than reproduce another map's names, lore, assets, exact class tree or encounters.
