# Game Vision

## Elevator pitch

DiceFree is a persistent isometric 3D action RPG for solo play and eventual 1–4 player co-op. Every character begins as a humble Novice and repeatedly advances into increasingly specialized classes while exploring the six outer faces of the Dice, running dangerous dungeons, hunting rare equipment, discovering secret progression paths and building long-term account-wide legacy.

## Core fantasy

**Start as nobody. Become something ridiculous.**

Advancement should be one of the game's strongest emotional beats. A class change can alter abilities, passives, visuals, equipment identity and playstyle.

## Pillars

### 1. Class evolution
The class tree should feel like a lineage. Each advancement is a meaningful transformation and a reason to make another character.

### 2. Persistent world progression
Characters persist between sessions. Regions, quests, dungeons, difficulties and bosses create a long progression ladder.

### 3. Loot that changes play
Stat upgrades matter, but memorable loot should alter abilities, summons, status effects, resource loops or class behaviour.

### 4. Discoverable secrets
Not every class, boss, item or system should be visible from the beginning. Achievements, hidden conditions and world interactions can reveal new paths.

### 5. Visible character growth
Equipped gear must appear on the character wherever practical. Class advancement should also make the character look increasingly distinctive.

### 6. Solo viable, co-op excellent
A player should be able to progress alone. Co-op should add synergy and fun without requiring a rigid tank/healer/DPS composition for ordinary progression.

## Inspirations

Primary structural inspiration:
- Warcraft III persistent ORPG custom maps, especially Twilight's Eve ORPG.

Design DNA carried from DiceBound:
- secret class unlocks;
- account progression;
- escalating difficulty modes;
- build-changing legendary/mythical loot;
- strange and funny classes;
- bosses, secret bosses and achievements;
- a willingness to let systems become gloriously deep.

DiceFree must remain an original game rather than reproduce another map's names, lore, assets, exact class tree or encounters.
