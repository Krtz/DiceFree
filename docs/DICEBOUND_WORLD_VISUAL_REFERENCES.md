# DiceBound -> DiceFree World Visual References

DiceFree's six outer faces should take their **visual DNA** from the corresponding DiceBound Board screen and Normal combat backgrounds.

This is inspiration/continuity, not a mandate to literally reproduce a 2D image in 3D.

## Source rule

For each face, consult both:
1. the DiceBound **Board background** for the broad Road identity;
2. the DiceBound **Normal combat background** for grounded environment/terrain/mood.

The resulting DiceFree face should feel like a large explorable world that plausibly expresses the same visual idea from the outside of the Dice.

## Progression principle

DiceBound's Normal backgrounds deliberately progress from:
**bright welcoming woodland -> increasingly hostile/mysterious landscapes -> ashen gothic endgame**.

DiceFree should preserve that broad visual escalation even though players can physically visit faces out of intended order.

## World 1 priority

Only Face 1 is currently being expanded into detailed geography/content.

Do not use this mapping as an excuse to fully design Faces 2–6 yet.
