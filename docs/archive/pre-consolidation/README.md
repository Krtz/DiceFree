# Historical branch material

These documents preserve earlier design and progression evidence. Current gameplay, later approved decisions, and the current save schema take precedence. In particular, the Novice pacing audit describes the retired linear XP curve; the current curve is quadratic.

The branch inventory records every remote head fetched before consolidation, unique history and each branch's delta from its merge base. Restored original first-party shield, shoes and hat assets retain their original paths and GUIDs. More recent Novice body/animation/prefab revisions stay authoritative.

The earlier feature/47 Options implementation was replaced by feature/48 and the current Input/UI implementations. Its alternative code remains in the consolidated Git history rather than introducing duplicate controls systems. Likewise, older narrative/progression documents do not overwrite later approved class and manifestation rules.

Original raw licensed downloads and generated licensed resources stay local. They are not part of the public source consolidation.
